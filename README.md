A clean, modern, and minimal **Dating App UI** built with Flutter.  
This project focuses purely on **UI/UX design**, showcasing a smooth front-end for a modern matchmaking experience.  
👉 All core screens are ready — only backend functionality needs to be added!

---

## 🎨 Highlights

- 🧼 **Clean and minimal UI**
- 💕 Modern design inspired by top dating apps
- 📱 Fully responsive for all screen sizes
- 🔄 Smooth card swipe & match interactions (UI only)
- 🔔 Placeholder for notifications & chat features
- 🌙 Light & modern visual style

---

## 📱 Screens Included

| Screen | Description |
|--------|-------------|
| 🔐 **Welcome / Login** | Simple onboarding UI (no auth logic) |
| ❤️ **Home / Match Screen** | Swipeable cards showcasing profiles |
| 💬 **Chats List** | Preview of active chats (UI only) |
| 🗨️ **Chat Window** | Clean text message UI |
| 👤 **Profile** | User settings and preview screen |
